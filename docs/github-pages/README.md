# GitHub Pages

Публичный статический сайт документации (п. 5 задания 6).

## Публикация
1. В настройках репозитория GitHub → **Pages** → Source: `Deploy from a branch`.
2. Выбрать ветку `main`, каталог `/lab4/task6/docs/github-pages`.
3. Сайт станет доступен по адресу `https://<user>.github.io/<repo>/`.

## Структура
- `index.html` — главная страница документации.
- `infrastructure_container.png` — контейнерная диаграмма инфраструктуры.
